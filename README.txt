# Nazar Birthday Website 🎀

A personal, girly scrapbook-style birthday website for Nazar.

## Features
- Secret birthday entrance screen
- Password protected opening
- Full birthday message and story
- Me, Nazar & Ruhi Appi section
- Gym Bro section
- 1 A.M. Calls
- Everything Bad I Learned
- You're Stuck With Me
- Final Letter
- Interactive surprise + confetti
- Floating hearts
- 17 uploaded memories arranged as Polaroid scrapbook photos
- Responsive mobile layout

## Secret password

The current password is:

nazar

To change it, open `script.js` and find:

const password = "nazar";

Replace `nazar` with whatever password you want.

## How to open

Keep the folder structure unchanged, then double-click `index.html`.
It opens directly in Chrome/Edge. No server is required.
